# Pavo 完整拆解 & 复刻方案

> 调研日期：2026-10-09　依据：官网实测资料 + 3 张真实界面截图 + 6 篇深度评测
> 产品原名：Pavo（新加坡 Sapiens Technology，品牌 Agnes AI）→ 我方命名：**林的视频工作台**

---

## 一、Pavo 是什么

一句话：**把「写剧本 → 出角色 → 拆分镜 → 画关键帧 → 生成视频 → 合成成片」整条链路塞进一个网页**，用一块无限画布管理所有素材，用 Agent 自动跑流程。解决的是「抽卡贵、角色崩脸、素材来回传」三个痛点。

- 形态：纯 Web（+ iOS/Android），无需安装
- 底座：自研 Agnes 全模态模型（文本 / 图像 / 视频），另接 Seedance、Kling、GPT Image、Nano Banana 等第三方
- 商业模式：自研模型免费 + 每日 200 积分 + 四档会员（59/169/599/999 元）
- 关键机制：**Harness 多 Agent 框架**（理解意图 → 匹配风格 → 设计镜头 → 串联全链路，带上下文记忆）

## 二、信息架构（这是 1:1 复刻的骨架）

```
顶栏：Logo | 搜索 | 积分/升级 | 通知 | 头像
左侧栏（5 个入口 + 底部）：
  灵感 / 短剧 / 画布 / 作品 / 资产   |   设置 · 用户
```

| 页面 | 做什么 |

## 三、界面视觉规范（从真实截图实测取值）

**重要：Pavo 是浅色白底，不是深色。** 这点最容易做错。

| 元素 | 取值 |
|---|---|
| 页面/画布背景 | `#F7F8FA` ~ `#FAFAFB`，画布带极淡点阵网格（点 `#E6E8EB`，间距约 20px） |
| 卡片 / 节点 | `#FFFFFF`，边框 `1px #E9EAEE`，圆角 `14px`，阴影极轻（几乎无） |
| **品牌强调色** | **青绿色** `#17B8A6` 系（节点选中边框、连线、连接点 + 号、聚焦态） |
| 主按钮 | **纯黑实心**（`#111`），例：发送圆钮、`去创作 →` 胶囊按钮 |
| 正文 / 次要 / 更次 | `#111827` / `#6B7280` / `#9CA3AF` |
| 圆角体系 | 卡片 14px · 输入面板 20px · 胶囊/圆钮 999px |
| 图标 | 线性描边，约 1.5px，圆角端点 |
| 字体 | 无衬线（苹方 / 思源黑）；宣传物料用高对比衬线做标题 |

**设计气质**：像 Figma 那种「白底 + 细边框 + 大量留白 + 一个黑白主按钮 + 一抹青绿点睛」，很克制。没有紫粉渐变、没有发光、没有玻璃拟态。

## 四、核心模块拆解

### 1. 无限画布（重头戏，必须做）

**节点类型**（右键/双击空白处的「添加节点」面板，实测截图）：
```
添加节点：文本 · 图片 · 视频 · 音频 · 视频合成 · 导演台
添加资源：上传 · 从资产库添加
```

**交互细节（逐条）**：
- 节点**标题显示在卡片外侧左上方**（小灰字 + 小图标，如「文本节点 1」）
- 节点卡片左右两侧各有一个**圆形 + 连接点**（白底、青绿描边、青绿 + 号），左边入、右边出
- 拖端口连线 → **青绿细线带箭头**；可从一个节点向右拉出**多条分支**
- 节点内部有「**尝试：**」快捷区：自己编写 / 一句话生成剧本 / 文生图 / 文生视频 / 图片反推提示词
- **每个节点自带输入框**（大圆角面板）：写提示词 + 选模型 chip + 黑色圆形发送钮
- 多节点可**组合成一个带标题的容器**（截图里的「一句话生成剧本」大框套住文本节点1→文本节点2）
- 支持**多方向扩展、一键整理、旧版本完整保留**（可回溯）
- 相邻两张图可作为**首尾帧**，由视频模型自动补间

### 2. 剧情短片（Harness 六阶段，每步可确认/局部返工）
```
一句话/剧本 → 需求卡片（标题·梗概·总时长·画幅·风格）
           → 剧本大纲（角色·性格·场景·BGM）
           → 角色/场景/道具设计（可单独重绘）
           → 分镜脚本（镜号·景别·运镜·台词·时长）
           → 分镜关键帧（单镜头可重绘）
           → 视频片段 → 一键合成成片 → 下载
```

### 3. 图片生成工作区
文生图 / 图生图 / 局部重绘；最高 4K；用途：角色三视图、场景设定图、道具图、封面海报

### 4. 视频生成工作区
文生视频 / 图生视频 / **首尾帧** / 全能参考；720P–2K；4–12 秒；原生音画同步、自带运镜

### 5. 资产库
角色/场景/道具统一沉淀，作为分镜参考锚点 → 多镜头自动继承外观 → **解决崩脸**

### 6. 3D 导演台
画布内摆虚拟角色 + 虚拟机位，调姿势/比例，最多 12 个机位截图，导入本地模型，先生成前预演构图

### 7. 风格库 / 模板 / 社区 Remix
70+ 画风（2D/3D/真人/国风/像素…）、电商/海报/科普/古风模板一键套用、社区作品可复制提示词 + 二创

### 8. 音频
音色克隆、BGM 生成、音效、字幕烧录、口型对齐

## 七、登录页设计（去 AI 味）

**不做什么**（这些一看就是 AI 生成）：
- ❌ 居中一张卡片 + 紫粉渐变背景
- ❌ 登录/注册 tab 切换
- ❌ 大标题下面一堆 emoji 卖点
- ❌ 玻璃拟态 + 发光按钮

**做什么**：**左右分屏**
- 左：沉浸式视觉区——缓慢漂移的 mesh 光晕 + 细腻噪点 + 大字号衬线式标题 + 三条编号要点
- 右：克制的表单区——**只有下划线的输入框**、标签浮动、聚焦时底线青绿扫过、纯白主按钮带箭头位移、错误时轻微抖动
- 去掉 tab，注册改为底部一行文字链接切换

## 八、技术栈

- 前端：纯静态 HTML + 原生 ES Module（零构建，直接推 GitHub Pages）
- 后端（免费）：Supabase 免费档 —— Edge Function 做 CORS 代理（转发各家模型 API，绕过浏览器跨域），Storage 存图片/视频，Postgres 存档（可选）
- 数据：默认全在浏览器 localStorage；接上 Supabase 后可跨设备
- 3D：Three.js 0.160（已本地化到 `assets/vendor/`，离线可用）
- 视频合成：ffmpeg.wasm（浏览器内跑，不依赖后端）

### 为什么合成不用后端
Supabase Edge Function 跑在 Deno Edge Runtime 上，**不能执行 ffmpeg 二进制**。
所以「一键合成」改成在浏览器里用 ffmpeg.wasm 完成——零后端、零成本，代价是首次要下载约 30MB 内核。

### 已知限制
- ffmpeg.wasm 处理长视频较慢（纯 CPU 编码），建议先用低分辨率试排、定稿再出高清
- 成片是浏览器内的临时 blob 链接，刷新即失效，务必及时下载
- 模型返回的素材必须允许跨域读取，否则合成前要先经后端代理落地
